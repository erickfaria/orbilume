# Orbilume

- Work on feature branches. Never push directly to main or merge without explicit authorization.
- Run the local build and tests before committing.
- Keep dependencies minimal and preserve compatibility with the supported JOSM revision.
- Keep source, comments, interface text, documentation, and commit messages in English.
- Prioritize working functionality over extensive documentation.
- Keep telemetry and credentials out of the project.
- Never upload OSM changes automatically.
